# 原型一致性契约

`assets/dashboard.html` 是所有仓库共享的固定页面。分析任务只提供数据；需要改变资产时，必须回到 skill 实现任务中修改，而不是生成仓库专属皮肤。

## 视觉与布局

- 背景 `#f4f5f7`，面板白色，正文 `#20242c`，主 accent `#5363d7`，代码区 `#111827`。
- 字体使用系统 sans-serif，路径、符号、代码使用系统等宽字体。保持原型字号、64px 顶栏、214px 侧栏和卡片圆角/边框。
- 基础树桌面为三栏：导航、文件工作区、文件职责。调用视图为导航加工作区两栏，内容最大宽度 680px 居中。
- 7 类颜色固定：core 紫、adapter 青、data 金、infra 灰、utility 绿、test 红、docs 淡紫。分类分布和文件点使用同一语义色。
- 不引入 Understand Anything 的黑金主题、图谱画布、粒子背景或新组件体系。

## 基础文件树

- 侧栏依次显示“结构视图”“调用视图”，基础文件树默认激活。
- 目录包含展开图标、名称、摘要和直接文件计数；文件包含分类点、名称、入口标签、摘要和 VS Code 文件链接。
- 点击文件更新职责面板；1120px 以下使用抽屉，720px 以下将侧栏收进顶栏导航按钮，保留主题搜索和切换。
- 基础树中没有调用箭头、关系按钮、步骤标签或关系筛选。
- 搜索覆盖当前树的路径、名称和摘要；工具按钮展开或收起目录。

## 调用框图

- 标题显示真实视图名称、阶段数和代码位置数；搜索路径、符号、源码、调用表达式和对象。
- 阶段默认仅第一阶段展开，阶段卡显示序号、标题、描述和位置数。
- 节点默认收起源码，但必须显示路径、符号、行号范围、关键行内容和 VS Code 精确位置；有对象信息时显示对象/类型。
- 节点间箭头标注直接调用、HTTP/SSE、回调注入或流程继续及真实表达式。灰色细线只用于 sequence。
- 展开节点显示真实行号、高亮和独立 Agent 注释。附加证据有角色和独立跳转链接。
- 工具按钮展开或收起当前视图全部源码；调用视图使用各自源码展开状态；切回基础树恢复目录、搜索和滚动状态。

## 最终核对

在相同桌面视口比较原型与生成物的基础树、每个调用视图及源码展开状态，并补做窄屏检查。真实内容长度可以造成合理换行，但布局、配色、组件和渐进行为不能改变。

逐视图核对节点数、字段、箭头、注释和链接。所有树文件来自真实扫描，所有代码来自当前快照；不能沿用 RPent 示例文本。`vscode://file/<绝对路径>:<行>:<列>` 只做格式和目标校验，除非实际启动应用，不宣称测试了外部跳转。
